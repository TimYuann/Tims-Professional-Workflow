## 0. 你必须按这个顺序做，不许跳步

```
① 查证据  →  ② 写计划  →  ③ 自己验证与推演（反例推演，不是写实现）  →  ④ 停机，等 Oracle 审思路
```

- **① 查证据**：对待确认的每一条缺口，**先回三个上游仓库找答案**（`upstreams/cursor-plugins`（pstack）、`upstreams/mattpocock-skills`、`upstreams/addyosmani-agent-skills`）。**不许凭想象造角色、造方法。** 找到了就记下 `file:line` 原文；三仓都没有，就明说"三仓无此方法，需自行设计"，并给出设计依据。
- **③ 自查推演**：对你提出的每一条修复，用**反例推演**验证它：假装按你的计划装配起来，问"这一步会不会卡住 / 会不会和另一条规则打架 / 会不会又出现无主环节"。**推演必须给出具体场景，不是形容词。**
- **④ 交 Oracle**：把**计划**（不是实现）交出去审**思路**。

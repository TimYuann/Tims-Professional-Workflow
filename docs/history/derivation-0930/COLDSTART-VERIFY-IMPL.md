# 6. 我拿到的 `A9` 证据栏里有人写了一段摘要，但只写了「哈希：a2af075d」。按本库要求，这一行缺了什么？我该在哪找到要求？

## 答：缺 **4 项里的 3 项**。要求在 `workflow/registry.yaml` A9 段的 `evidence` 注记里（派生在 `docs/artifacts.md:89`）。

**（a）要求原文 —— `workflow/registry.yaml` A9 段 `notes.evidence`：**
> 「凭什么。**若用摘要**：注明**算法**、**对象／版本**、**完整值或明确标为前缀**、**来源**；
> 区分**本人实测**、**他人报告**、**转录**。不能复算或算法不明时**注明原因并记
> `UNVERIFIED`，不填默认算法**。**不强制**每项证据都有摘要，也不要求算满若干种算法——
> 没实测就不写，比写一个无据的标签诚实。**摘要不证明**独立评价、内容正确或安全性。」

**（b）拿「哈希：a2af075d」逐项对：**

| 要求项 | 这一行有没有 | 说明 |
|---|---|---|
| **算法** | ❌ **缺** | 原文只写「哈希」，`a2af075d` 是 7 位十六进制，未标 md5／sha1／sha256 |
| **对象／版本** | ❌ **缺** | 没有说是哪个文件、哪个版本、哪个 commit |
| **完整值或明确标为前缀** | ✅ 有 | `a2af075d` 明显是前缀（不足全长），符合「明确标为前缀」的**字面**——但没标哪一头是截断 |
| **来源** | ❌ **缺** | 没有区分「本人实测／他人报告／转录」 |

**（c）⚠️ 但要注意要求里两句反直觉的话（都是原文）：**
- 「**不强制**每项证据都有摘要，也不要求算满若干种算法——**没实测就不写，比写一个无据的标签诚实**」

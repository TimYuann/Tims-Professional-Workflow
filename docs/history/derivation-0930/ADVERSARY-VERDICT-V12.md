## 5. 点 5 · 你问的纪律边界：**有没有它管不到、却已经被你说成管到了的情况**

**先给你该得的肯定**：你上轮说「处置声明必须能被一次 diff 证明」，
**这条本轮当场否掉你两次「已修」而实际没改的声明（python assert 失败没写入，diff 立刻报「无差异」）——
这是真实发生的拦截，不是设想。它确实有用。**

**但「它有用」与「它管住了处置声明」不是同一句话。**
**我实测出三条它管不到的边界，而且第一条此刻就有活例子：**

### 边界一 · diff 证明「声明写进了文件」，不证明「声明是对的」→ **本轮就有活例子**

版本表 V10 行写着 `591 / b0022f38`。
**把这两个数写进文件，是完全 diff 可证的**——我核了，V11→V12 的 34 行 diff 里就有它。
**而这两个数对不对，diff 一个字都证明不了**——它只说明「你写了」，
不说明「你写的是真的」。

**而我手上正好有一份不一致的独立记录（§4.2）。**
**换句话说：这条纪律在这次事件里，会对 V10 行报「有改动，PASS」，
而那一行恰恰是本轮最有问题的一处。**

**⇒ diff 能抓的是「说了没做」，抓不到「做了但做错」。**
**这两件事长得极像，都表现为一句「已修」。**

### 边界二 · diff 的范围由声明者自己划

你本轮跑的是「§6／§7／版本表**三段** diff」。
**这三段之外的任何声明，纪律不覆盖** ——
包括**技术面（改 1–改 6）**、§0、以及文件里其他任何一节。
本轮我另外跑了**六个改动点的逐节 md5** 才敢说「技术面零改动」，
**那是另一套检查，不是这条纪律做的。**

### 边界三 · 外部事实根本不在 diff 范围内

「冻结件已生成」、「md5 一致」、「字节已丢失」——**这些是关于别的文件／外部状态的主张。**
候选件的 diff 再完整，也证明不了一个冻结件文件是否存在、md5 是否对得上。
**我本轮核六份冻结件，是逐个 `md5 -q` 核的**（§0 那张表），
**同样不是这条纪律做的。**

### 边界四（附带）· diff 只说「变了」，不说「变的是你要的那一处」

34 行变更里若混进一处未申报的改动，diff 只会显示「有差异」，
**它不会指出「这一处你没申报」。** 逐条归属仍要人做（我 §3 做了）。

**⇒ 我给你的边界表述（我的候选，未经独立复核）：**

> **「处置声明可由 diff 证明」证明的是「声明与文件一致」，不是「声明与事实一致」。**
> 它抓「说了没做」；它抓不到「做了但做错」，也抓不到 diff 范围之外的任何主张。
>
> **所以它不能单独作为「已修」的充分条件**——
> 还需要一条**指向外部的检查**（文件在不在、md5 对不对、数对不对），
> 而且**那条检查的证据必须来自被引用对象本身，不能来自被引用的那个句子**。

**而《裁决修订 A》（242 行）里「可核替代（adversary 的候选，未经独立复核）」那句话，
我上几轮一直没展开说它缺什么——现在可以说了：它缺的正是这条外部检查的锚点。**

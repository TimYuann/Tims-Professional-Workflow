## 5. 本轮 A9 的一条可复用教训

scribe 追加台账时写了「**shasum 前缀** `a2af075d440c`」——那是 **SHA-1**（macOS `shasum` 默认算法），
不是 SHA-256（同文件 sha256 为 `ec1479be45e092cc…`）。**md5 与行数都对，只有标签有歧义。**

问题不在数字为假，而在**同一个词在同一份台账里指两个算法**——
正是本库 `AGENTS.md` 禁止的「**任何含义都不在两处各自设值**」。

**A9 只追加 ⇒ 错行原样保留，靠更正行救。** 现已立下约定：**A9 里凡写哈希必须带算法名**
（md5 / sha1 / sha256），不得只写「shasum 前缀」。
**该约定目前只是本轮记录纪律，尚未升级为库级条文**（未改 `registry.yaml` / `AGENTS.md`）——是否升级待 Owner。

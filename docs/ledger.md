# 决策台账工具（A9）

`A9` 是全工作流唯一常驻的产物。`scripts/ledger.sh` 是它的追加工具。

**纪律：只追加。** 本工具没有删除和编辑功能，这是刻意的。
写错了就再追加一行说明上一行为什么错。

## 用法

```bash
# 追加一条决策
scripts/ledger.sh <台账路径> "决定了什么" "为什么" "凭什么" "结果如何"

# 例
scripts/ledger.sh .decisions/ledger.tsv \
  "用 append-only 的 TSV 记录决策" \
  "就地编辑会让人追溯性地改写历史；只追加让内容层不变" \
  "registry.yaml:A9.append_only" \
  "已建表，7 列"
```

台账文件不存在时会自动创建并写表头。

## 列

| 列 | 内容 |
|---|---|
| `ts` | ISO 8601 时间戳 |
| `decision` | 决定了什么，动词开头 |
| `why` | 为什么 |
| `evidence` | 凭什么：文件行号、命令输出、一次运行、或 `A2` 结论的 id |
| `result` | 结果如何，包括「后来发现错了」 |

## 它不做的事

- 不判断一条决策该不该记。
- 不检查 `evidence` 是否真实存在。**这一条只能靠写的人自觉，
  所以复核台账时必须抽查。**
- 不做任何汇总、统计、格式化。台账是原始材料，不是看板。
- 不写入临时目录。**需要留档的东西落在临时目录等于没写。**
